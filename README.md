# Aerolab — Página Web
 
Sitio web oficial de **Aerolab**, un proyecto divulgativo y gratuito para acercar conceptos de ciencia y aeronáutica de forma educativa y experimental. Incluye la presentación del proyecto y del simulador de vuelo para PC actualmente en desarrollo.
## Sobre el proyecto
 
Aerolab es un primer proyecto de emprendimiento personal orientado a la divulgación científica. Su eje central es un **simulador de vuelo para PC**, pensado como una herramienta de aprendizaje: permite "tocar" variables de física e ingeniería aeronáutica y observar sus resultados en tiempo real, en lugar de limitarse a explicaciones teóricas.
 
La primera versión del simulador está en desarrollo activo. La web nace como la puerta de entrada al proyecto: explica qué es Aerolab, muestra el estado del simulador y convierte las visitas en una acción concreta (lista de espera o descarga/demo cuando esté disponible).
## Objetivo de la web
 
- Explicar Aerolab en segundos, mostrar el simulador (PC) y convertir visitas en una acción clara: lista de espera o descarga/demo cuando esté lista.
## Estructura del sitio
 
### Home / Landing (one-page)
 
1. **Hero + CTA** — lista de espera / waitlist
2. **Qué es / What it is** — presentación breve del proyecto
3. **Simulador (PC) / Simulator (PC)** — estado y adelanto del simulador
4. **Qué aprenderás / What you'll learn** — conceptos de física e ingeniería que se trabajan
5. **Roadmap** — 3–5 hitos del proyecto
6. **FAQ** — preguntas frecuentes
7. **Footer** — contacto + Instagram

### Secciones opcionales
 
- **Blog / Articles** — artículos cortos en ES/EN, orientados a SEO y a construir comunidad.
- **Simulador / Simulator** — devlog, builds, changelog y capturas de pantalla del desarrollo.

  
## Idiomas
 
Contenido bilingüe (ES/EN) para ampliar el alcance de la divulgación y facilitar el SEO en ambos idiomas.

## Estado
 
En desarrollo. La web acompaña en paralelo el desarrollo del simulador, priorizando por ahora la landing principal (hero, presentación, CTA de lista de espera) sobre las secciones opcionales de blog y devlog.
